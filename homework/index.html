Homework brief

Agent-Guided Transformer Co-design

Transformer inference performance depends on both accelerator resources and the programs that use them. Hardware choices affect compute throughput, data movement, and storage, while program choices determine how effectively those resources serve prompt prefill and autoregressive decode.

In this homework, use your own AI agent to explore the design space. Submit one accelerator configuration and two assembly programs that run on the same hardware, produce correct Transformer outputs, and improve the combined simulated score. The full assignment statement provides the exact workload, rules, starter package, and submission format.
